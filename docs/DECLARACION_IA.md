# Declaración de uso de Inteligencia Artificial

Para el desarrollo de este proyecto se utilizaron las siguientes herramientas y fuentes de apoyo:

- **ChatGPT/Codex de OpenAI:** apoyo en la organización del repositorio, corrección de código, resolución de errores, creación de pruebas automatizadas, configuración de GitHub Actions y mejora de la documentación técnica.
- **Blackbox AI:** apoyo en la revisión de fragmentos de código y búsqueda de soluciones para problemas surgidos durante el desarrollo.
- **Perplexity AI:** búsqueda y contraste de información relacionada con Git, GitFlow, microservicios, automatización y prácticas DevOps.
- **Material académico de DUOC UC disponible en AVA:** fuente principal para comprender los contenidos, conceptos y requerimientos establecidos en la asignatura y en la pauta de evaluación.

El equipo revisó, ejecutó y validó el código, las pruebas, el workflow de GitHub Actions y los archivos de documentación antes de incorporarlos al proyecto.

- **Fuente institucional sobre el uso y citación de Inteligencia Artificial:** [Bibliotecas Duoc UC](https://bibliotecas.duoc.cl/ia)

Las conclusiones, justificaciones técnicas y reflexiones individuales fueron redactadas personalmente por cada integrante, sin apoyo de Inteligencia Artificial, conforme a las instrucciones de la evaluación.
